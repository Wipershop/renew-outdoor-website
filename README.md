# Renew Outdoor Website — Prototype v2

Static replacement-site prototype for Renew Outdoor.

## Included pages

- `index.html` — homepage
- `window-cleaning.html` — window cleaning service page
- `gutter-cleaning.html` — gutter clearance service page
- `commercial.html` — commercial cleaning page
- `franchise.html` — prominent franchise landing page
- `styles.css` — responsive site styling
- `script.js` — mobile navigation + copyright year
- `robots.txt`
- `sitemap.xml`

- Real Renew Outdoor photography still needs to replace the design photo placeholders.
